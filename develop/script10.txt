脚本 10：main_api.py 开发提示词
功能描述
实现 FastAPI 应用入口，整合前9个脚本的所有模块，提供 /parse 端点用于处理单据解析请求。该端点接收 doc_type 和多个图片文件，按顺序执行以下操作：

生成 trace_id

预处理每张图片（缩放、编码 base64、上传 MinIO）

从 MySQL 加载配置（fields_schema, profile, agg_rules）

逐页串行调用字段提取（利用 process_page）

跨页聚合结果（利用 aggregate_results）

将最终结果写入数据库（利用 save_results）

返回 JSON 响应

要求使用异步处理，错误处理完善，日志记录详细，并支持通过环境变量或配置文件加载连接参数（数据库、MinIO、VLM）。

输入（HTTP 请求）
doc_type: 表单字段，字符串，单据类型（如 "letter_of_credit"）

images: 表单字段，一个或多个图片文件（支持 PNG/JPEG 等）

输出（HTTP 响应）
成功时返回 {"trace_id": str, "fields": dict, "warnings": list}，状态码 200

失败时返回 {"trace_id": str, "error": str}，状态码 500（或其他 4xx/5xx）

uvicorn（用于运行）

前9个脚本中的所有模块

端点内部流程伪代码
python
async def parse_document(doc_type, images):
    trace_id = trace_manager.new_trace()
    try:
        # 1. 预处理所有图片
        tasks = []
        for img_file in images:
            raw = await img_file.read()
            tasks.append(preprocess_image(raw, target_short_edge))
        processed_images = await asyncio.gather(*tasks)  # 返回 bytes 列表
        base64_list = [encode_to_base64(img) for img in processed_images]
        
        # 2. 上传到 MinIO（可选，不影响主流程）
        minio_paths = []
        for idx, img in enumerate(processed_images):
            obj_name = f"{trace_id}/page_{idx+1}.jpg"
            path = await upload_to_minio(img, bucket, obj_name, ...)
            minio_paths.append(path)
        
        # 3. 加载配置
        config = await load_config(db_url, doc_type)
        fields_schema = config["fields_schema"]
        profile = config["profile"]
        agg_rules = config["agg_rules"]
        
        # 4. 逐页提取（串行）
        all_page_results = []
        total_pages = len(base64_list)
        for page_num, b64 in enumerate(base64_list, start=1):
            # 获取该页需要提取的字段（根据 profile 中的 pages 属性）
            fields_for_page = []
            for field_name, field_cfg in profile["fields"].items():
                pages_cfg = field_cfg.get("pages", [])
                if pages_cfg == "all" or page_num in pages_cfg or (pages_cfg == "last" and page_num == total_pages) or (pages_cfg == "first" and page_num == 1):
                    # 合并 fields_schema 中的类型信息
                    full_cfg = {**field_cfg, "field_name": field_name, "type": fields_schema.get(field_name, {}).get("type", "string")}
                    fields_for_page.append(full_cfg)
            if not fields_for_page:
                continue
            page_res = await process_page(b64, fields_for_page, page_num, vlm_config)
            # 添加 minio_path 和 page 信息
            for res in page_res:
                res["page"] = page_num
                res["minio_path"] = minio_paths[page_num-1]
            all_page_results.append(page_res)
        
        # 5. 聚合
        final_fields, agg_decisions = aggregate_results(all_page_results, agg_rules)
        
        # 6. 存储
        async with db_session() as session:
            await save_results(session, trace_id, doc_type, total_pages, final_fields, [], all_page_results, agg_decisions)
        
        return {"trace_id": trace_id, "fields": final_fields, "warnings": []}
    except Exception as e:
        logging.exception(f"Request {trace_id} failed")
        return {"trace_id": trace_id, "error": str(e)}

注意事项
需要保证所有前9个脚本已实现并正确导入（可使用相对导入或设置 PYTHONPATH）。

数据库连接 URL 构建：mysql+aiomysql://{user}:{pass}@{host}:{port}/{database}。

MinIO 桶需事先创建或在 upload_to_minio 中自动创建（已实现）。

对于 pages 属性的解析逻辑（"all", "first", "last", 列表）应放在 main_api 中，保持 process_page 简单。

由于 process_page 中已经包含了字段提取，不需要在此重复调用 extract_field。

如果某些字段在 fields_schema 中没有类型定义，默认视为 string。

返回的 warnings 第一阶段可留空（或添加一些非致命错误，如字段缺失）。
